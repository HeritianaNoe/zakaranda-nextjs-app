# Portfolio – RASOLOMANANA Heritiana Noe

Modern bilingual (French / English) portfolio for a Mobile Developer specialized in **Flutter** and **Java**.

Built with **Next.js 16**, **TypeScript** and **Tailwind CSS**.

## Features

- 🌐 Language switcher (FR / EN) with localStorage persistence
- 📱 Fully responsive design
- ✨ Dark modern UI with gradients and smooth animations
- 📂 Sections: Hero, About, Skills, Projects, Contact
- ⚡ Fast and SEO-friendly

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for production

```bash
npm run build
npm start
```
